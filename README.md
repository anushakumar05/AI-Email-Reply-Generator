# Email Assistant
An AI-powered tool to generate email replies efficiently.

Email Assistant is a full-stack application that helps users automatically generate email responses using AI. It includes:
- **Frontend**: React app for user interface.
- **Backend**: Spring Boot service for processing requests and generating AI responses.
- **Browser Extension**: Integrates Email Assistant into your browser for quick email replies.

## Repository Structure
Email Assistant/
├─ frontend/ → React app (UI)
├─ backend/ → Spring Boot backend API
├─ email-assistant-ext/ → Browser extension
├─ hello-world-ext/ → Sample extension for testing
├─ README.md → This file

### Frontend
1. Navigate to `frontend/`
2. Install dependencies:
   ```bash
   npm install
3. Start the frontend:
   npm start

### Backend
Navigate to backend/
Build and run:
./mvnw spring-boot:run

## **5. Usage**
How to use the app after it’s running.
1. Open `http://localhost:3000` in your browser.
2. Enter the email content you want a reply for.
3. Click "Generate Reply" to get an AI-generated response.
